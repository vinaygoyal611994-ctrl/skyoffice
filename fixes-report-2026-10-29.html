Resolved Issues
Login & Authentication
1
Office Login Redirecting to Home Page After Login Bug
After a successful office login, the user was being sent to the site's home page instead of the office dashboard. The root cause was a competing navigation triggered by a background data refetch that fired before navigation completed. Fixed so that every role is taken directly to its correct dashboard after login.
Office Login
2
Wrong Credentials Show Raw Error Code on Admin Login UX
Entering incorrect credentials on the Admin Login page was displaying raw server error codes such as INVALID_CREDENTIALS directly to the user. The error display now shows clear, human-readable messages for all error scenarios including wrong credentials, locked accounts, and deactivated accounts.
Admin Login
3
Office User Able to Log In via Customer Login Portal Security
An office account could successfully authenticate through the Customer Login page, gaining unintended access. The Customer Login portal now strictly validates the role — only customer accounts are accepted. Any other role is rejected with a message directing the user to their correct login portal.
Customer Login · Role Enforcement
4
Customer User Able to Log In via Office Login Portal Security
Similarly, a customer account could authenticate through the Office Login page. Role validation has been added to the Office Login portal — only office accounts are accepted, with a clear message for any mismatch.
Office Login · Role Enforcement
5
Logged-In Admin Could Access the Admin Login Page UX
An admin who was already logged in could still navigate directly to the Admin Login URL and see the login form. The page now detects an active admin session and automatically redirects to the dashboard, preventing the login form from appearing unnecessarily.
Admin Login · Session Guard
6
Admin Logout Redirecting to Wrong Page Bug
Logging out from the admin dashboard was redirecting to the public home page of the site. Admin logout now correctly redirects to the dedicated Admin Login page so the admin can sign back in without manual navigation.
Admin Logout
Admin Dashboard
7
Admin Dashboard Opening on Last-Visited Section Instead of Overview UX
After login, the admin dashboard was restoring whichever section was last visited — often Account Settings — instead of opening the main Command Center. Admins now always land on the Overview (Command Center) immediately after logging in.
Admin Dashboard
8
KPI Cards Not Navigating to Relevant Sections UX
Clicking on Key Performance Indicator cards in the Command Center was not navigating anywhere. All cards are now clickable and take the admin directly to the relevant section — Office Management, Customers, or Intelligence Hub. Cards showing zero are kept non-interactive since there is nothing to view.
Admin Command Center
9
KPI Cards Not Filtering by Status When Navigating UX
Clicking "Active Offices (10)" was navigating to Office Management but showing all 11 offices instead of only the active ones. Each KPI card now passes its corresponding status filter — clicking Active Offices shows only active offices, clicking Suspended shows only suspended ones, and so on.
Admin Command Center · Office Management
10
Verify Office Action Had No Feedback and Was Slow Performance
Clicking Verify Office or Unverify Office showed no confirmation and required a full list reload before the change was visible, making it feel unresponsive. The action now updates the verified badge instantly and shows a success toast message. If the server request fails, the change is automatically rolled back.
Office Management · Verify Office
11
Deactivate Account Dialog Had Broken Layout UX
The Deactivate Account confirmation dialog in Customer Management had a stretched and misaligned layout — large empty space, oversized Confirm button, and misaligned Cancel/Confirm pair. The dialog is now compact with a properly sized textarea, aligned buttons, and a loading indicator on the Confirm button while the action is processing.
Customer Management · Deactivate Dialog
12
Dropdown Menu Items Had No Pointer Cursor UX
Action menu items such as View Details, Open Public Profile, Verify Office, and Delete Permanently did not show a pointer cursor on hover, making them feel non-interactive. All dropdown menu items across the platform now correctly display a pointer cursor.
Office Management · Dropdown Menus
Customer Account
13
No Option to Update Name or Phone Number Feature
Customer accounts had no way to update their profile information after registration. An Edit Profile section has been added to the customer account page where users can update their full name and phone number. Changes are saved immediately without requiring a logout.
Customer Account · Edit Profile
14
No Option to Change Password for Customers Feature
Customers had no way to change their account password. A Change Password section has been added with current password verification and a new password confirmation field, each with a show/hide toggle. On success, the session is securely terminated and the user is redirected to log in with their new password.
Customer Account · Change Password
