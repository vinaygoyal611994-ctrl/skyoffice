Session Fixes — 15 November 2026
1
Admin Video Call Log Panel
New Feature

⚠ Problem

Admin had no visibility into video call bookings. There was no way to see which customer requested a meeting, which office accepted it, what status the booking was in, or whether a Zoom meeting was created.

✓ Solution

A new "Video Call Log" section was added to the admin panel. It shows a full paginated list of all video call requests with customer name & ID, office name & ID, preferred date/time/timezone, booking status badge, Zoom link indicator, and when the request was submitted. Supports filtering by status (All, New, Accepted, Completed, Declined, Cancelled, etc.) with bilingual Arabic/English support.

2
Video Call Log Showing 0 Requests (API Duplicate Route Bug)
Bug Fix

⚠ Problem

After deploying the Video Call Log panel, the admin section was showing "0 requests" even though real video call bookings existed in the database. The filter and pagination had no effect.

✓ Solution

Investigation revealed two duplicate API routes registered on the same path. The first (older) route was always matched first by Express and returned a plain array in the wrong format — missing pagination fields like items, total, and totalPages that the frontend expected. The duplicate was removed and the existing route was updated to return the correct paginated format with all required fields.

3
Timezone Not Visible in Video Call Log
UX Improvement

⚠ Problem

The admin Video Call Log showed date and time for each booking but not the customer's timezone. This made it difficult for the admin to understand the actual scheduled time, especially for customers in different regions.

✓ Solution

Timezone is now displayed below the date and time in the Date/Time column of the Video Call Log. It appears in a subtle muted style (e.g. Asia/Riyadh) so it is visible without being visually dominant.

4
WhatsApp & Email Mandatory Validation in Office Profile
Validation

⚠ Problem

The office profile update form had no validation on the WhatsApp number or email fields. The email field was not even marked as required despite being the login credential. Offices could save a profile with an invalid number format or empty email.

✓ Solution

Both fields are now mandatory with proper validation. WhatsApp accepts digits only (with optional + prefix, 7–15 digits). Email must be a valid email format. Both show a red error message in Arabic or English if invalid. The Save button is blocked until errors are resolved. Errors clear automatically as the user types.

5
Tooltips Added to All Media Upload Sections
UX Improvement

⚠ Problem

Office users had no indication of which file types were accepted or what size limits applied before attempting an upload. This caused confusion and failed uploads, especially for the marketing video section which has stricter requirements (MP4 only, 75-second limit).

✓ Solution

An info (ⓘ) tooltip icon was added next to the title of every upload section. Each tooltip clearly shows the allowed file types, maximum file size, recommended aspect ratio, and item limits. Tooltips were added to: Quick Card Cover, Decision Card Main Image, Marketing Video, Decision Card Gallery (positions 2–4), and Works Gallery. All tooltips are bilingual (Arabic & English).

6
Double "+" Symbol in Add Work Button
Bug Fix

⚠ Problem

The "Add work" button in the Works Gallery tab displayed as "+ + Add work" with a duplicate plus symbol. This looked unprofessional and was clearly a UI defect visible to all office users.

✓ Solution

The issue was caused by a "+" character hardcoded inside the translation string AND a separate Plus icon component in the button. The duplicate "+" was removed from the translation string so only the icon-based plus remains, displaying correctly as "+ Add work".

7
Tooltip Added to Documents Upload Section
UX Improvement

⚠ Problem

The Verification Documents section (ID/Passport, Trade License, Professional License, Additional Certificate) provided no information about which file formats were accepted for document uploads. Users were left guessing and sometimes attempted unsupported formats.

✓ Solution

An info (ⓘ) tooltip was added to the "Verification Documents" card title. Hovering shows the allowed types (PDF, JPG, PNG) and the maximum file size (15 MB), helping users prepare and upload their documents correctly on the first attempt.

8
Reschedule Call Dialog Redesigned for Professional Look
Bug Fix

⚠ Problem

The Reschedule Call popup dialog had oversized, stretched buttons that filled the full width of the dialog footer. The dialog itself was too wide and the overall layout looked unpolished and inconsistent with the rest of the platform's design language.

✓ Solution

The dialog was redesigned with a narrower max-width, compact input fields, and right-aligned small buttons with a separator line above the footer. Buttons now use proper compact sizing and no longer stretch to fill the container, giving the dialog a clean, professional appearance consistent with standard modal UX patterns.
