U1
Admin Activity Log — Excessive Right-Side Whitespace
Frontend UI / Layout
✅ Fixed
🔴 Problem

The Activity Log section in the Admin panel was displaying all log data squeezed into the left portion of the card, leaving the entire right side completely empty. There were no defined column widths, so the action labels and metadata were wrapping unpredictably. There were also no column headers to help the reader understand what each piece of information represented, making the log difficult to read at a glance.

🟢 Solution
  • Replaced the unstructured flex row layout with a proper 3-column grid that spans the full width of the card — a fixed-width timestamp column on the left, followed by two equal-width columns that fill the remaining space.
  • Added a column header row at the top of the log listing the three columns: Time, Event / Actor, and Target / Details — so the admin can immediately understand what each column contains.
  • The timestamp column is set to always display left-to-right (even in Arabic mode) to ensure dates are always readable in a consistent format.

U2
Admin Intake Queue — Missing Search Bar
Frontend UI / UX
✅ Fixed
🔴 Problem

The All Offices section in the Admin panel had a search bar allowing admins to quickly filter offices by name, email, phone, city, and more. However, the Intake Queue (Registration Requests) section — which shows all incoming office applications — had no search functionality at all. With a large volume of applications, the admin had to manually scroll through the entire list to find a specific office. This inconsistency between two adjacent sections was also confusing for users.

🟢 Solution
  • Added a search bar above the application list, following the exact same visual design as the All Offices section — a search icon inside the left edge of the input for a consistent look across the Admin panel.
  • Search works instantly across six fields: office name, email, phone, city, category, and office ID — all case-insensitive, with no additional API calls needed.
  • A results count line appears below the status filter chips (e.g. "12 results") so the admin always knows how many applications match the current search.

U3
Office Profile Card — Button Group Spacing
Frontend UI / Layout
✅ Fixed
🔴 Problem

The office profile page displayed three action buttons — WhatsApp, Book Video Call, and Request a Service — with cramped and inconsistent spacing. The buttons were too close together and the "Book Video Call" button used a smaller text size with no icon-label gap, making it look visually different from the other two buttons on the same card. The overall appearance felt unpolished and unbalanced.

🟢 Solution
  • Increased the spacing between the three buttons to give them comfortable breathing room, making the button group easier to tap and more visually balanced.
  • Restyled the "Book Video Call" button to match the other buttons: full width, standard text size, and a consistent gap between the icon and the label — so all three action buttons now look like they belong to the same design family.
