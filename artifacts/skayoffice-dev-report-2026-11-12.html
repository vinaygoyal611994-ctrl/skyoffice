01
Admin Account Settings — Right Side Blank
Frontend UI / Layout
✅ Fixed
🔴 Problem

When an admin logged in and navigated to the Account Settings page, only a narrow "Change Password" card appeared on the left side of the screen. The entire right half of the page was completely empty with no content, making the page look unfinished and wasting large amounts of screen real estate.

🟢 Solution
  • Changed the layout from a single narrow card to a 2-column grid that fills the full page width.
  • Left column retains the existing Change Password form unchanged.
  • Right column now shows two informational cards: Password Requirements (minimum 8 characters, one letter, one number) and Security Tips (don't share password, use unique passwords, rotate regularly, automatic sign-out on change).
  • Fully bilingual — both cards display correctly in Arabic and English.

02
Media Section — No Image Format Guidance for Upload
Frontend UX
✅ Fixed
🔴 Problem

In the Media section of the Office Dashboard, the Quick Card Cover Image upload area gave the user no information about what file types or size limits were accepted. Users had no way to know in advance whether their file would be accepted or rejected, leading to failed uploads and confusion.

🟢 Solution
  • Added a small ⓘ info icon next to the "Quick Card Cover Image" section title.
  • Hovering over the icon shows a tooltip with the allowed file formats (JPG, PNG, WebP) and the maximum file size (8 MB).
  • The tooltip is fully bilingual — displays in Arabic when the UI language is Arabic.
  • No clutter is added to the UI — the information is hidden until the user needs it.
📁 File Changed

03
Contact Features — Video Call Booking Stuck on "Coming Soon"
Frontend UI
✅ Fixed
🔴 Problem

The Video Call Booking row in the Contact Features section of the Office Dashboard was showing a "Coming Soon — Optional Feature" badge and the toggle was permanently disabled. However, the full video call booking system (with Zoom integration, meeting creation, reschedule, and cancel flows) had already been completely implemented. The UI was not updated to reflect this, so office owners had no way to enable or disable this feature from their settings.

🟢 Solution
  • Removed the "Coming Soon" badge entirely from the Video Call Booking row.
  • Removed the dimmed / faded appearance (opacity reduction) from the row so it looks equal to the other contact feature rows.
  • Enabled the toggle switch — office owners can now turn Video Call Booking on or off from their Contact settings like any other feature.
  • When the toggle is turned ON, a small reminder hint appears below the description prompting the office to ensure their Zoom account is connected in Integration settings.
📁 File Changed

04
Reschedule Call Dialog — Oversized Unprofessional Buttons
Frontend UI / Layout
✅ Fixed
🔴 Problem

The "Reschedule Call" dialog displayed two action buttons — Cancel and Confirm Reschedule — that were oversized and appeared as large square blocks at the bottom of the dialog. 05
Login Page — No Redirect for Already Logged-In Users
Frontend UX / Auth
✅ Fixed
🔴 Problem

If an office user was already logged in and navigated to the login page (/login/office), the login form was shown again instead of sending them directly to the dashboard. The same problem existed for customer users on the /login/customer page. This forced users to either fill in the login form a second time or manually navigate to their dashboard — a poor and confusing user experience.

🟢 Solution
  • Added an authentication check to both the Office and Customer login pages that runs as soon as the page loads.
  • If the user's session is already valid and their role matches, they are automatically redirected before the login form ever renders: office users go to /office/dashboard, customer users go to /account.
  • If the user is not logged in, the page behaves exactly as before — the login form is shown normally with no change to the login flow.
